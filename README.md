# Практические работы по ТИП

Кистанов Илья Тимофеевич, группа ЭФБО-08-26.

В репозитории каждая практическая работа лежит в своей папке. Внутри папки находятся файлы работы и README с описанием решения.

Практическая работа №1 выполнена в Scratch. Задача состояла в том, чтобы убрать условный оператор из вычисления B по A, где A принимает значения 0 или 1. Решение сводится к формуле B = 2 - A.

Практическая работа №2 выполнена на C++. Решены три задачи: обмен значений двух переменных без третьей переменной, слияние двух отсортированных массивов за один цикл и поиск пропущенного числа в массиве за один цикл.
