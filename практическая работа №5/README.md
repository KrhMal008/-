# Практическая работа №5

Кистанов Илья Тимофеевич, группа ЭФБО-08-26.

Программа читает два числа a и b и превращает a в b с помощью двух команд: разделить на 2 и вычесть 1. Если a чётное и после деления на 2 не станет меньше b, программа делит, иначе вычитает единицу, и каждую команду выводит на экран. Например, для a = 10 и b = 3 программа выведет :2 и затем -1 два раза. Рабочий вариант написан через цикл for, а ниже в комментариях оставлены тот же алгоритм через while, do while, for с break и while (true).
