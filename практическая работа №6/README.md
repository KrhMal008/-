# Практическая работа №6

Кистанов Илья Тимофеевич, группа ЭФБО-08-26.

В файле main.cpp три задачи. Первая читает число n и строит таблицу n на n, где по побочной диагонали стоят единицы, выше неё нули, а ниже двойки. Вторая это поле сапёра: программа читает размеры поля и координаты мин, ставит на месте мины звёздочку, а в каждую соседнюю клетку добавляет единицу, так что в итоге в клетке стоит число мин вокруг неё. Ниже в комментариях оставлен второй способ решения этой же задачи через поле с запасом по краям, чтобы не проверять выход за границы. Третья задача строит последовательность «посмотри и скажи»: программа читает строку и число n и n - 1 раз заменяет строку её описанием, например 1 превращается в 11, потом в 21, потом в 1211. Задачи запускаются по очереди, ненужные на время закомментированы.
