В работе решены три задачи на языке C++. Каждая задача лежит в отдельном файле: zadacha1.cpp, zadacha4.cpp и zadacha5.cpp. Программы для задач 1 и 5 читают данные с клавиатуры через cin, в задаче 4 массивы заданы прямо в коде. Ответ выводится через cout. Компилировать можно любым компилятором, например командой g++ zadacha1.cpp -o zadacha1, и затем запустить полученный файл.

Задача 1. Даны две числовые переменные a и b, нужно поменять их значения местами без третьей переменной, используя только присваивание и арифметику. Идея в том, что сумму двух чисел можно хранить в одной из переменных, а потом вычитанием восстанавливать нужное значение. Сначала выполняется a = a + b, теперь в a лежит сумма. Затем b = a - b, то есть из суммы вычитается старое b и получается старое a, оно записывается в b. Потом a = a - b, из суммы вычитается старое a, которое уже лежит в b, и получается старое b. Проверка на примере из условия: при a = 4 и b = 5 после первого шага a = 9, после второго b = 9 - 5 = 4, после третьего a = 9 - 4 = 5. Значения поменялись местами.

Задача 4. Даны два массива A и B, оба отсортированы по возрастанию, нужно за один цикл длиной a + b вывести все элементы обоих массивов в порядке возрастания. Массивы заданы прямо в коде: A = 1 4 9 и B = 2 3 5 10. Программа хранит два индекса: i показывает, на каком элементе стоим в A, j показывает, на каком элементе стоим в B. В конец каждого массива записывается очень большое число, миллион. Оно работает как заглушка: когда один массив закончится, индекс укажет на неё, она всегда проиграет сравнение, и дальше числа будут браться только из второго массива. Поэтому не нужно отдельно проверять, кончился ли массив. Цикл выполняется ровно a + b раз, на каждом шаге сравниваются текущие элементы A[i] и B[j], выводится меньший, а его индекс сдвигается на единицу. Так как оба массива отсортированы, самое маленькое из ещё не выведенных чисел всегда стоит либо на позиции i в A, либо на позиции j в B, и результат получается отсортированным. Программа выводит 1 2 3 4 5 9 10.

Задача 5. Дан неупорядоченный массив из n различных целых чисел от 0 до n, одно число из этого диапазона пропущено, и его нужно найти за один цикл. Сумма всех чисел от 0 до n считается по формуле n * (n + 1) / 2. Программа в одном цикле читает элементы массива и накапливает их сумму. Разность между полной суммой и суммой массива и есть пропущенное число, потому что все остальные числа в обеих суммах присутствуют и взаимно сокращаются. Например, для n = 5 и массива 0 1 2 4 5 полная сумма равна 15, сумма массива равна 12, ответ 3.

Вывод. Во всех трёх задачах ограничение на количество переменных или циклов обходится за счёт арифметики: обмен через сумму и разность, слияние отсортированных массивов через два индекса и число-заглушку в одном цикле, поиск пропущенного числа через формулу суммы арифметической прогрессии.
