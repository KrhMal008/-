# Практическая работа №1

Кистанов Илья Тимофеевич, группа ЭФБО-08-26.

Содержание работы. Требовалось убрать условный оператор «Если» из блока, в котором переменная A принимает значение 0 или 1: если A = 0, то B = 2, иначе B = 1. Использовать любые другие условные операторы, в том числе вида ?(A = 0; 2; 1), не разрешалось. Значения связаны линейно: пара (A = 0, B = 2) и пара (A = 1, B = 1) — это две точки, а через две точки проходит ровно одна прямая, поэтому ветвление заменяется одной арифметической формулой B = 2 - A. Проверка по обоим допустимым значениям: при A = 0 получаем 2 - 0 = 2, при A = 1 получаем 2 - 1 = 1, то есть результат совпадает с исходным условным оператором, а само ветвление из программы исчезает.

Решение реализовано в среде Scratch 3.32.1, файл проекта Практическая_работа_1_Задача_3.sb3. Всё решение — это один блок «задать B значение (2 - A)». Условных операторов и их аналогов в проекте нет нигде.

Устройство сцены. Слева находится окно «МЕНЮ» с пятью кнопками: «A = 0» и «A = 1» задают значение переменной A и запускают разбор, «Алгоритм» запускает рассказ о том, откуда взялась формула, «Проверка» проговаривает проверку обоих случаев, «Сброс» возвращает всё в исходное состояние. Сверху расположено табло с текущим видом формулы. Справа внизу проходит числовая ось с двумя отметками — 1 и 2, это единственные значения, которые может принять B. Текущие значения A и B выведены на сцену мониторами переменных.

Как анимация показывает смысл алгоритма. Спрайт «Герой» разыгрывает вычисление по шагам и проговаривает каждый из них репликами. Сначала он объявляет исходные данные и встаёт на отметку 2 — это константа, с которой начинается формула. Затем сообщает, что вычитает A, и вычитание показывается физически: цикл «повторить (A)» заставляет его сделать ровно A шагов влево. При A = 0 шагов нет и он остаётся на отметке 2, при A = 1 он делает один шаг и переходит на отметку 1. Тем самым «минус A» на сцене — это буквально сдвиг на A делений. После шага герой называет отметку, на которую пришёл, табло переключается на конкретный вид формулы (B = 2 - 0 = 2 или B = 2 - 1 = 1), и герой пересчитывает результат прыжками: их ровно B. В конце он произносит ответ и говорит, что оператор «Если» не понадобился.

Количеством шагов и прыжков управляют значения переменных A и B в блоках «повторить», а не проверка условия, поэтому вся демонстрация тоже обходится без ветвления. Переключение костюма табло сделано тем же приёмом: номер костюма вычисляется выражением 2 + A, а не выбирается условием.

Звук. В проекте четыре собственных звука. Короткий подъём звучит в начале разбора, сухой щелчок — на каждом шаге вычитания, мягкий сигнал — на каждом прыжке при пересчёте, аккорд из двух нот — когда результат получен. Звук привязан к действию, поэтому на слух тоже понятно, сколько шагов сделано.

Чтобы запустить работу, нужно открыть редактор Scratch (сайт scratch.mit.edu или Scratch Desktop 3.32.1), выбрать «Файл» — «Загрузить из компьютера», указать файл Практическая_работа_1_Задача_3.sb3, нажать зелёный флаг и затем кнопку «A = 0» или «A = 1» в меню слева.

Вывод. Если область значений входной переменной конечна и мала, условный оператор избыточен и заменяется арифметическим выражением. Для A из множества {0, 1} таким выражением является B = 2 - A, что даёт линейный код без переходов и ветвлений.
