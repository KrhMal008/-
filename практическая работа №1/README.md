# Практическая работа №1

Кистанов Илья Тимофеевич, группа ЭФБО-08-26.

Содержание работы. Требовалось убрать условный оператор «Если» из блока, в котором переменная A принимает значение 0 или 1: если A = 0, то B = 2, иначе B = 1. Использовать любые другие условные операторы, в том числе вида ?(A = 0; 2; 1), не разрешалось. Значения связаны линейно: при A = 0 нужно получить 2, при A = 1 нужно получить 1, поэтому ветвление заменяется одной арифметической формулой B = 2 - A. Проверка по обоим допустимым значениям: при A = 0 получаем 2 - 0 = 2, при A = 1 получаем 2 - 1 = 1, то есть результат совпадает с исходным условным оператором, а само ветвление из программы исчезает.

Решение реализовано в среде Scratch 3.32.1, файл проекта Практическая_работа_1_Задача_3.sb3. В проекте собран визуальный алгоритм с меню, окнами и кнопками. Слева на сцене находится окно «МЕНЮ» с пятью кнопками: «A = 0» и «A = 1» задают значение переменной A и запускают анимацию, «Алгоритм» открывает окно с разбором решения, «Проверка» открывает окно с проверкой обоих случаев, «Сброс» закрывает окна и возвращает спрайт в исходное состояние. Окна показываются и скрываются сообщениями, щелчок по окну его закрывает. Текущие значения A и B выведены на сцену мониторами переменных.

Само решение в Scratch — это один блок «задать B значение (2 - A)». Анимация спрайта привязана к результату: после нажатия кнопки спрайт «Герой» с двумя костюмами проходит столько полных кругов, сколько получилось в переменной B. При A = 0 значение B равно 2 и спрайт делает два круга, при A = 1 значение B равно 1 и спрайт делает один круг. Количеством повторений управляет цикл «повторить (B)», то есть значение переменной, а не проверка условия, поэтому условных операторов в проекте нет нигде.

Чтобы запустить работу, нужно открыть редактор Scratch (сайт scratch.mit.edu или Scratch Desktop 3.32.1), выбрать «Файл» — «Загрузить из компьютера», указать файл Практическая_работа_1_Задача_3.sb3, нажать зелёный флаг и затем кнопку «A = 0» или «A = 1» в меню слева.

Вывод. Если область значений входной переменной конечна и мала, условный оператор избыточен и заменяется арифметическим выражением. Для A из множества {0, 1} таким выражением является B = 2 - A, что даёт линейный код без переходов и ветвлений.
